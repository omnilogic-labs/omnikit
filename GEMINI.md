# Omnikit

Cross-platform agent skills by Omnilogic Labs.

This repository is also a Gemini CLI extension. Skills are in the `skills/`
directory, a generated set of symlinks pointing at the canonical sources in
`plugins/*/skills/*/`. Run `bash install.sh` to rebuild those symlinks and link
this clone as an extension; do not hand-edit `skills/`.

Available skills: agent-browser, artistic-vision, onepassword, plain-writing,
plan-forge, plan-queue, primer, render, task-triage, task-tracking,
worktree-pipeline.
